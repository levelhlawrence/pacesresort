# Paces Worldwide Resort

The marketing website for **Paces Worldwide**, a resort property. It's a single-page site with sections for Home, About, Gallery, and Contact, built to showcase the property, its rooms, villas, and surroundings, and to drive bookings.

Live site: [retreat.pacesworldwide.com](https://www.retreat.pacesworldwide.com)

## Project Structure

```
pacesresort/
├── LICENSE
├── README.md
└── pacesworldwide/   # React application (see its README for setup)
```

The app itself lives in [pacesworldwide/](pacesworldwide/) — see that folder's README for how to install, run, and deploy it.

## Tech Stack

- [React](https://reactjs.org/) (via Create React App)
- [Tailwind CSS](https://tailwindcss.com/) for styling
- [React Router](https://reactrouter.com/) for navigation
- [GitHub Pages](https://pages.github.com/) for deployment
